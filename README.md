Project Name : বাজার দর 


Project Description : দৈনন্দিন বাজারের পণ্যের দাম জানুন এক নজরে!

BazarDor is a responsive web application that helps users explore and compare the prices of everyday essential products across different local markets (Bazars). Users can view daily price updates, track price increases and decreases, explore product details, and compare market-wise prices through a simple and user-friendly interface.


Technologies Used: 

1) Next.js - Frontend development and routing 
2) React - Building reusable UI components 
3) TypeScript - Type safety and maintainable code
4) Tailwind CSS - Responsive styling 
5) DaisyUI - UI components and styling 
6) Better Auth - Authentication and user management 
7) React Hot Toast - Toast notifications 
8) Lucide React - Icons 
9) MongoDB - Database 
10) Vercel - Deployment 


Key Features:
1. Responsive Design: Fully responsive user interface optimized for mobile, tablet, and desktop devices.

2. Daily Price Updates: Explore essential product prices with indicators showing daily price increases and decreases.

3. Product Details: View detailed product information, including minimum, maximum, and average prices, along with market-wise price comparisons.

4. Category-Based Browsing: Browse products by category and sort them by price from low to high or high to low.

5. User Authentication: Secure registration and login functionality using Better Auth, including Google and GitHub social authentication.

6. Protected Routes: Restrict access to product details and profile-related pages to authenticated users.

7. User Profile Management: View profile information and update your account name.

8. Interactive Notifications: Get toast notifications for successful actions, authentication events, validation errors, and other important updates.

9. Loading Skeletons: Display loading skeletons while product data is being fetched for a smoother user experience.

10. Market Price Ticker: View continuously scrolling price updates for essential products.
